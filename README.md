# Drum Kit

Interactive drum pad — play sounds with mouse clicks or keyboard keys.

**Live demo:** [aritra59.github.io/Drum_kit](https://aritra59.github.io/Drum_kit/)

## Features

- Seven drum pads (`w` `a` `s` `d` `j` `k` `l`)
- Click or keypress triggers sounds
- Local drum images and MP3s (toms, snare, crash, kick)

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

```bash
git clone https://github.com/Aritra59/Drum_kit.git
cd Drum_kit
```

Open `index.html` in a browser.
